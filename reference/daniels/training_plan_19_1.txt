# ---------------------------------------------------------------- Распределение недель по фазам
#
# Правило Дэниэлса: программа сжимается или растягивается под срок до
# старта, и **недели программы перетасовываются между фазами**. Одна и та
# же неделя программы в разных сроках попадает в разные фазы.
#
# Формат:
#   BASE  <недель_до_старта> <фаза>:<недели> ...   — базовая таблица
#   EXTRA <фаза,фаза,...>                           — куда идут лишние недели
#   SCHED <недель_до_старта> <фаза>:<недели> ...   — явное правило для срока
#
# Недели перечислены явно, а не заданы количеством: при сжатии программы
# недели перетасовываются между фазами, и одна и та же неделя программы
# в разных сроках попадает в разные фазы. Считать «6 недель первой фазы»
# нельзя — это другая неделя программы.
#
# Кирилл, 30.10.2026 (4 сообщения): «даю тебе на мировой неделе, которые
# попадают в фазу» — то есть перечисление недель **программы** (1-24),
# которые входят в фазу при данном сроке до старта.
#
# При 24 неделях до старта:
#   фаза I  ← недели 1, 2, 3, 13, 21, 23
#   фаза II ← недели 10, 11, 12, 18, 19, 20
#   фаза III ← недели 7, 8, 9, 14, 15, 16
#   фаза IV ← недели 4, 5, 6, 17, 22, 24
#
# Правило для других сроков (Кирилл, 30.10.2026):
#   - короче 24: та же таблица, недели программы сверх срока отпадают;
#   - длиннее 24: фазы собираются из своих недель программы подряд
#     (I — недели 1-6, II — 7-12, III — 13-18, IV — 19-24), а лишние
#     недели программы (25, 26, …) идут по кругу через фазы из EXTRA и
#     дописываются в конец своей фазы. Например, 29 недель: 5 лишних →
#     2 в фазу II, 2 в фазу III, 1 в фазу IV. Фаза I не растёт.
#
# План тренировки для лишней недели — из хвоста своей фазы:
#   - одна лишняя неделя: LAST — последняя неделя фазы (II — 12, III —
#     18, IV — 24);
#   - две и больше: хвост фазы из PLANS, по кругу. Фаза II — 11, 12;
#     фаза III — 17, 18; фаза IV — 21, 22 (третья и четвёртая, а не
#     пятая и шестая: в пятой и шестой — чисто гонки).
#
# Формат: PLANS <фаза>:<недели> ...
#         LAST  <фаза>:<неделя> ...
