# ---------------------------------------------------------------- Распределение недель по фазам
#
# Правило Дэниэлса: программа сжимается под срок до старта, и **недели
# программы перетасовываются между фазами**. Одна и та же неделя программы
# в разных сроках попадает в разные фазы.
#
# Формат: SCHED <недель_до_старта> <фаза>:<недели> ...
#            BASE  <недель_до_старта> <фаза>:<недели> ...
#
# SCHED — правило для этого срока: какие недели программы попадают в фазу.
# BASE  — базовое распределение для остальных сроков.
#
# Кирилл, 30.10.2026 (4 сообщения): «даю тебе на мировой неделе, которые
# попадают в фазу» — то есть перечисление недель **программы** (1-24),
# которые входят в фазу при данном сроке до старта.
#
# При 24 неделях до старта:
#   фаза I  ← недели 1, 2, 3, 13, 21, 23
#   фаза II ← недели 10, 11, 12, 18, 19, 20
#   фаза III ← недели 7, 8, 9, 14, 15, 16
#   фаза IV ← недели 4, 5, 6, 17, 22, 24
#
# Каждая фаза — 6 недель, и все 24 недели программы распределены.
