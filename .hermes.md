# Конституция Coach App

Правила проекта. Написаны так, чтобы их можно было соблюсти при написании кода,
а не проверить постфактум. Каждое правило — с командой проверки.

Источники правды для проектирования:
- `specs/domain/DOMAIN-SPEC.md` — доменная модель (18 сущностей, 43 инварианта)
- `specs/logical/LOGICAL.md` — логический уровень (7 подсистем)
- `specs/design/*.md` — контрактный и физический уровни

## Слои и зависимости

1. **Зависимости строго вниз:** `api → services → ports → domain`. Обратная зависимость
   запрещена.
   *Проверка:* `grep -rn "^from app\.\|^import app\." app/domain app/ports | grep -v "app.domain"` — пусто.

2. **Домен не знает о формате хранения, HTTP и времени.** В `app/domain/` нельзя
   импортировать `json`, `sqlite3`, `os.path`, `requests`, `fastapi`, `datetime.now`.
   *Проверка:* `python3 tools/check_storage_leaks.py` — зелёный.

3. **Доступ к данным — только через порты.** Пять портов хранения: `SeasonRepo`,
   `FactRepo`, `AthleteRepo`, `MethodologyRepo`, `CommandLog`. Ни один метод не упоминает
   формат хранения: нет параметров `path`, `table`, `query`.
   *Проверка:* `python3 tools/check_storage_leaks.py` — зелёный.

4. **Адаптеры реализуют порты и не импортируют `api` или `services`.**
   *Проверка:* `grep -rn "app.api\|app.services" app/adapters` — пусто.

## Данные

5. **Источник правды один.** Производное пересчитывается, а не хранится вторым
   экземпляром. Кэш клиента — производная, помечена версией.

6. **У документа данных есть версия схемы и миграция.** Старые данные читаются.
   *Проверка:* `python3 -m pytest tests/ -k migration` — зелёные.

7. **Запись атомарна.** Во временный файл → переименование. Читатель никогда не видит
   половину записи.

8. **Никаких зашитых путей.** Код не зависит от текущей директории.
   *Проверка:* `grep -rn '"/home/\|"\./state\|"state/' app/` — пусто.

## Отказоустойчивость

9. **Внешний мир — только через адаптер.** У каждого внешнего вызова: timeout, retry,
   понятная ошибка.

10. **Деградация вместо отказа.** Недоступный Garmin или календарь ограничивает, но не
    роняет приложение. Сервис, от которого зависит команда, отвечает `degraded`.

11. **Идемпотентность.** Повтор команды с тем же `id` не применяет её дважды.

12. **Граничные входные данные не роняют.** Пустое значение, отсутствующее поле,
    невалидный объект → понятное сообщение и безопасное поведение, не исключение.

## Тесты

13. **На каждое доменное правило — тест.** Имена тестов = номера инвариантов:
    `test_i09_link_is_bidirectional`.
    *Проверка:* `python3 tools/check_invariant_coverage.py` — все 43 покрыты;
    `python3 -m pytest tests/unit -q` — зелёные.

14. **Тест обязан падать до фикса.** Сначала красный, потом зелёный.

15. **Тесты детерминированы и быстрые.** Без сети, без «сейчас». Полный прогон — секунды.
    *Проверка:* `python3 -m pytest -q` — зелёные за секунды.

## Спецификации

16. **Источник правды — MD, HTML — производная.** Правки в `specs/**/*.md`, потом
    `python3 tools/build.py`. HTML руками не править.
    *Проверка:* `python3 tools/build.py && git diff --exit-code` — пусто.

17. **Счётчики спецификации проверяются.** Числа в шапке совпадают с фактическими.
    *Проверка:* `python3 tools/count_spec.py DOMAIN-SPEC.html specs/domain/DOMAIN-SPEC.md`.

## Стиль

18. **Один файл — одна ответственность.** Больше ~300 строк — повод разбить.

19. **Никакой магии.** Явные зависимости, нет глобальных переменных, нет побочных
    эффектов при импорте.

20. **Комментарий объясняет «почему», не «что».**

21. **Незавершённое помечено явно** (TODO с причиной), а не живёт месяцами как «Phase 2».

## LLM в контуре

22. **Один вызов через порт `NarratorPort`.** Есть детерминированная заглушка, работает
    без ключа и без сети. Ответ валидируется по схеме. Промпты — в коде или данных.

23. **LLM не считает и не применяет.** Только формулирует: объяснить, предложить вариант,
    задать вопрос. Числа считает домен.

## Намерения

Не проверяются автоматически, но держат в голове:
- приложение работает без агента и без LLM;
- парольная аутентификация отложена, сейчас — токен-проверка;
- внешний доступ отложен, в базе — локальная сеть.
