## Принципы

1. **Решения принимает код.** LLM только формулирует. Числа считает домен.
2. **Ничего не инициируется само.** Любое изменение состояния — команда от пользователя.
3. **Источник правды один.** Производное пересчитывается, не хранится вторым экземпляром.
4. **Логика не знает о формате хранения.** Доступ к данным — только через порты;
   формат (файлы, база) знает только адаптер. Проверяется чекером, не договорённостью.
5. **Деградация вместо отказа.** Упавший внешний источник ограничивает, но не роняет.
6. **Один пользователь.** Ничего не строим на будущее, чего этот пользователь не делает.
7. **Заглушка честнее выдумки.** Нет правила — «не могу оценить», а не выдуманное число.

## Границы с существующим пайплайном

`~/coach` — рабочий пайплайн, он не переписывается. Приложение — отдельный
репозиторий, на первом этапе читает состояние импортом из `~/coach/state/*.json`.
Пайплайн остаётся источником батч-рендеров (HTML-превью недель) — решение №9.
