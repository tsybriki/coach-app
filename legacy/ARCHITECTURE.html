Coach App — Architecture

Клиент (PWA, mobile + offline) · API · Мозг (domain + services) · Adapters

Ключевые решения

  • Мозг — код, не LLM. LLM только объясняет и предлагает варианты; числа, темпы, объёмы считает домен.
  • Offline = read-only кэш + outbox. Просмотр недели, сессий, сезона работает без сети; команды копятся и уходят при появлении сети.
  • Операции с планом — команды, а не правка файла. «Неделя = выходная» → Replanner пересобирает хвост сезона и отдаёт diff.
  • Всё, что видно в UI, — проекция одного снапшота сезона. UI не знает, как считается план.

Домен (ядро)

  • Session: дисциплина, subkind, focus, steps[], rationale
  • Step: phase + basis (time | hr_zone | pace | interval | rpe) + reps×(on+off)
  • Week: season_week, даты, слоты, цель, фаза, load targets
  • SeasonPlan: goals[], phases[], gates[], rules[]
  • Preferences: календарь недели (день→время) + окна оборудования (бассейн ПН/ПТ)
  • Athlete / Actual: форма, HR-зоны, VDOT, травмы · выполнено

Что есть · что строить

  • Есть (~/coach): step_builder, goal_allocator, daniels, actual_load, plan_generate, season_week; state/*.json как правда
  • Строить: API/BFF, PWA-клиент, доменная типизация Step, Replanner/Adjuster (сейчас stub), прогресс-метрика (VDOT)
  • Открыто (нужно решение): где живёт сервер и синхронизация между устройствами; граница полномочий LLM в решениях; штраф за «перенос недели» (потеря объёма vs сдвиг фазы)
